# meta-ctx

Raw source context behind the project: meeting transcripts, notes, and decisions
captured while shaping the idea.

These are working records, not documentation. They are kept verbatim so the
reasoning behind design choices stays traceable. For the synthesized version of
what we are building, see [the build plan](../docs/plan.md).

## Adding to this directory

- **Wispr Flow:** copy the note's summary and transcript into a dated Markdown file.
- **WhatsApp:** export the thread from the app (Chat → Export chat → *Without media*)
  and commit the `.txt` alongside a short header noting participants and date.
