## First working slice

1. Choose one task with an objective success check and a small example dataset.
2. Produce an initial result, evaluate it, and pass the failure evidence into a bounded retry.
3. Trace the generation, evaluation, and revision with W&B Weave.
4. Show the initial and final results together with scores and trace links.
5. Have another teammate run the project from a clean checkout.

Integrate this path before splitting into larger backend, UI, and agent tasks. Add tools or multiple agents only when they help the chosen problem.
