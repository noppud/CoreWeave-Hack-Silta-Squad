`media-manifest.json` provides hashes for the included media and exact edit points. No generated machining frames are used. The snapshots retain original paths and timestamps for provenance; media loading uses only relative paths. The source runs remain in the Fusion evidence archive.

`fusion-campaign.json` is an older explicitly timestamped campaign inventory: 14 drawings with verified candidates, 13 completed drawings, 43 job runs and 67 candidate attempts. `learning-transfer.json` selects 13 completed drawings. These are different cohorts; retries and later stage retests are not additional distinct parts. Neither inventory is a 27-part measured learning curve.

The demonstrations use internal Fusion simulation and finished-stock comparison. Indexed work uses a Haas UMC750 in 3+2 with one T1 12.7 mm flat cutter. The two persisted endpoint checks apply to the recorded 3-axis fixture/setup and do not validate arbitrary indexed motion. Weave records evidence; the six-case replay does not enable a promotion gate. Weave project access may require the existing account.

For a short stage pitch, use slides 1–6 and 11; slides 7–10 provide the concrete examples and deeper inspection. The full film is a selectable clip rather than mandatory narration time.
