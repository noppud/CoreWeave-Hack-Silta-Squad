# Narration for the 116-second film

**0–8 seconds.** The part stays fixed. Our agent changes the machining plan, checks it, simulates stock removal, and only then judges its machining time.

**8–23 seconds.** Here is the actual indexed machining replay. The table reorients the part between cuts. The movement plan drives the cutter and the remaining-stock display.

**23–35 seconds.** On three new complex parts, all reference and best plans pass. Estimated machining time falls from seventy-six minutes to twenty-one: a seventy-two point five percent reduction. These are constant-speed simulator estimates. After timing feedback, the carrier improves another six point four percent; the manifold ties.

**35–50 seconds.** The staggered drum has twenty-six features across seventeen indexed orientations. The output includes the machined-stock mesh and the movements that produced it. The drum’s next proposal is slower, so the loop keeps its earlier passing plan. Every candidate faces the same frozen geometry, tool library, and verification constraints.

**50–62 seconds.** Here the simulator rejects a manifold plan. Astra receives the failure and changes its CAM; the revised plan passes. The saved exact-match check then catches two repeat failures without rejecting the two valid controls.

**62–68 seconds.** These are the actual scored records in Weave, with separate geometry gates and machining-time measurements.

**68–74 seconds.** ARIA reviewed the evidence. We tested its suggested cleanup experiment, then retained only the narrow advice the results supported.

**74–82 seconds.** Twenty-four plans across four parts show mixed memory transfer. The new geometries do not confirm a general speed benefit. We keep that result and the failure-avoidance evidence separate.

**82–90 seconds.** These indexed multi-face parts show the same movement-driven machining replay.

**90–110 seconds.** This is the recorded output of a fresh PDF job: generated CAM, verification, timing feedback, and saved memory. Waiting time is compressed. We can inspect the underlying artifacts directly in the live demo.

**110–116 seconds.** This prototype uses one-millimetre cells and three-millimetre demo tolerance. Now let’s run a new drawing.
